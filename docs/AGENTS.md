# docs/ — hosted API documentation

Mintlify site (`mint.json`) plus `openapi.yaml` documenting the hosted Upscayl Cloud API at docs.upscayl.org, not
the desktop app. The pages under `api/`, `tasks/`, `upload/`, `history/`, and `start-a-new-task.mdx` mirror that
API.

`docs/README.md` states these Markdown files are not regularly updated and that the GitHub wiki
(docs.upscayl.org) is canonical. Do not treat this directory as the source of truth for app behavior; verify against
the code. The Requestly test collection is documented in `../apis/AGENTS.md`.
