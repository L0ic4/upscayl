# models/ — sample custom models (not built in)

Holds `realesr-animevideov3` sample models at x2, x3, and x4. Nothing in the app or build references this
directory; built-in models are shipped from `resources/models` and listed in `common/models-list.ts`.

Use these only as examples for manual testing of the custom-model folder flow (`upscayl-bin -m models`), for
instance after copying them into a folder named `models`.
